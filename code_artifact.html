門市 VIP 查詢與雙軌計價自動化系統

問題背景與系統解法

門市前線人員面對進廠車主時，以往須人工查閱多張實體車主卡或不同活頁簿，導致算價耗時、容易核算錯誤。我獨立運用輕量化前端技術結合雲端架構開發出直覺查詢介面：

// 系統資料流架構
[門市現場查詢] ➔ Web 前端響應式介面（HTML/CSS/JS）
➔ Google Apps Script（後端邏輯運算與權益驗證 API）
➔ Google Sheets 雲端資料庫（輕量化會員與即時價目對照表）
➔ 一秒即時呈現：精準折扣金額、歷史保養紀錄與建議換胎方案

效益與實務成果

  • 工時縮短：現場報價查詢時間從原本 3-5 分鐘縮減至 5 秒內，整體行政工時下降逾 40%。
  • 錯誤率歸零：系統自動計算雙軌折抵方案與折扣上限，免除前線人工計算錯誤與收費爭議。
  • 零額外軟體支出：全面基於 Google Workspace 原生環境建置，零伺服器維護費與授權年費。
